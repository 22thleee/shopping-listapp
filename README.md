# 🛒 shopping-listapp

브라우저 `localStorage`에 자동 저장되는 간단한 쇼핑 리스트 웹앱입니다. 별도의 빌드나 서버 없이 단일 HTML 파일로 동작합니다.

## 기능

- 아이템 추가 / 삭제
- 체크(구매 완료) 표시 및 취소선
- 체크된 항목 일괄 삭제
- 남은 항목 / 전체 항목 개수 표시
- 새로고침해도 데이터 유지 (localStorage 자동 저장)
- 라이트 / 다크 모드 자동 대응

## 사용 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

```
open index.html
```

## 기술 스택

순수 HTML / CSS / JavaScript (의존성 없음)
